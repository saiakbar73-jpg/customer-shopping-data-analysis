# Customer Shopping Data Analysis

## Project Overview
This project analyzes customer shopping data using Python and Pandas. The goal is to understand sales performance, compare products, and identify useful business insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## Project Objectives
- Calculate total and average sales.
- Identify the highest and lowest sales values.
- Analyze customer purchasing patterns.
- Compare sales across products.
- Analyze sales across cities.
- Filter customers based on sales values.
- Visualize sales data using charts.

## Key Skills Demonstrated
- Data analysis using Python
- Data filtering and grouping
- Data aggregation
- Exploratory data analysis
- Data visualization
- Business insight generation

## Project Files
- `custumer analysis.ipynb` — Jupyter Notebook containing the analysis and visualizations.

## Conclusion
This project demonstrates how Python and Pandas can be used to analyze shopping data, summarize sales performance, and communicate findings through visualizations.
